# Instagram · @navidadbga

Material de publicación con precios del catálogo. `plan.json` guarda el orden de las imágenes, el pie de foto y el estado de cada publicación.

Las fotos conservan su composición de estudio y se convierten de WebP a JPEG para Instagram. No incluyen precios ni textos añadidos sobre la imagen. Las cinco figuras de anime no forman parte de estas tandas.

La portada está en `perfil/portada.png` y `perfil/portada.jpg`. Se creó con ImageGen integrado; el prompt se conserva en `perfil/generacion.json`.

El enlace externo está pendiente de que el usuario lo añada desde la app móvil de Instagram.
